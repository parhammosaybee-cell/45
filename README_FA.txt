PM Chat نسخه تنظیمات و پروفایل عمومی

Build Command: pip install -r requirements.txt
Start Command: uvicorn main:app --host 0.0.0.0 --port $PORT

این نسخه پنل تنظیمات، نام نمایشی، درباره من، انتخاب رنگ رابط، تعویض عکس و نمایش عکس کنار پیام‌ها را دارد. برای اینکه فایل‌های عکس و دیتابیس بعد از redeploy روی Render بمانند، Persistent Disk را به مسیر data وصل کن. نام نمایشی هنوز هویت تأییدشده نیست؛ برای استفاده عمومی واقعی، احراز هویت و کنترل سوءاستفاده لازم است.
